# Markets

Contest definitions and resolution rules for Spiral Dreams.

## v0.1 Priority Categories (Maximum Game Energy)

1. Short-horizon crypto / token moves (1h–24h)
2. Public figure / cultural flashpoints
3. Tech / AI capability or release timing
4. Macro / political binaries with clear near-term resolution
5. Internet / platform weather (viral moments, outages, rankings)

These categories are chosen for volatility, emotional charge, and existing speculative attention.

## Design Constraints

- Questions must have clear, objective resolution criteria.
- Resolution source and timing must be stated at market creation.
- Fast feedback loops preferred in the early phase to accelerate reciprocity data.
- The 35% mandatory return and 72-hour window apply to all markets.
